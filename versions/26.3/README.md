# Minecraft 26.3 adapter

This adapter reuses the shared portal engine, definitions, designs, and
dimension resources. It owns the 26.3 Fabric entrypoint, command integration,
portal mixin, and tests. The shared catalog includes the 26.3 dappled forest
biome and all biomes available in earlier supported releases.

Build it with:

```bash
./gradlew build -PversionLine=26.3
```
